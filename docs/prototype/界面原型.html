这一版可以真的点

  • 两侧共用一个滚动轨道：滚动任意一侧，另一侧必然同步，不会错位
  • 顺序为「相同文件 → 仅 A 侧 → 仅 B 侧 → 跳过项」，相同组按行左右对照，多副本按索引配对
  • 每行独立勾选；勾满整组会被拦截（每组至少留 1 份）
  • 点缩略图看大图；视频封面带时长与播放标记
  • 底部批量「移入隔离区 / 回收站 / 永久删除」→ 预览 → 执行 → 回执与日志
  • 仅 A 侧 / 仅 B 侧的标题栏里有「剪切到另一侧」，即 FR-10 归并

模拟部分与取舍

  • 12 组 / 27 副本 / 6+4 个独有文件 / 4 个跳过项均为示例数据
  • 缩略图为示意照片，不代表真实文件内容；视频只有封面没有播放
  • 两侧用同一滚动容器实现同步，代价是行高统一为 56px —— 若真实程序要各自独立滚动，需额外做滚动位置同步与行高对齐
  • 「保留 A 侧 / B 侧」是批量预选，不直接执行删除
